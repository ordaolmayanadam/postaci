# Code of Conduct

[Türkçe](CODE_OF_CONDUCT.md) · **English**

Postacı is a project open to everyone's contributions. We want an environment where everyone can take part
comfortably, regardless of experience level, age, gender, sexual orientation, disability, ethnicity, religion,
nationality, language or appearance.

## Expected behaviour

- Be respectful and constructive; criticize code and ideas, not people.
- Be patient with newcomers; show the way instead of asking "don't you know this?".
- Be open to different views; explain your reasoning in a disagreement and, if needed, accept the maintainer's
  decision.
- Don't take credit for others' work; if you used AI or other sources, say so.
- Respect privacy: don't share anyone's personal information, mail content or contact details without permission.

## Unacceptable behaviour

- Insults, humiliation, harassment, threats or discriminatory language.
- Sexualized language or imagery.
- Persistently bothering someone, trolling, deliberately derailing discussions.
- Publishing others' personal information (address, email, phone, etc.) without permission.
- Submitting malicious code, harmful links or spam.

## Enforcement

These rules apply to issues, pull requests, discussions and all communication on behalf of the project in this
repository. The repository owner may edit or delete comments that break these rules, reject contributions and, if
necessary, temporarily or permanently remove people from the project.

If you see a violation, contact the repository owner through the contact option on their GitHub profile or use
GitHub's **Report content** feature. Reports are kept confidential.
